# StreamViewer

YouTube / Twitch 用の自作マルチビュアーです。Holodex のマルチビュー画面を参考に、
以下の機能を実装しています。

- 複数配信を1つの画面内に同時表示
- 画面サイズ・配置を自由にドラッグ＆リサイズ、レイアウトを「プリセット」として保存・呼び出し・書き出し(JSON)
- 配信ごとの音量調整（ミュート切替も可能）
- 配信中の動画だけでなく、アーカイブ(過去動画/VOD)の一覧表示・視聴
- チャットの表示、および書き込み（YouTube/Twitch公式のチャット埋め込みを利用）
- 登録チャンネル(YouTube)・フォロー中チャンネル(Twitch)の一覧表示 → クリックで追加
- スマートフォン(Android含む)のブラウザでも動作。ホーム画面に追加してアプリのように使用可能(PWA)

**ビルド不要（npm install不要）** です。素のHTML/CSS/JavaScriptだけで作られているので、
ファイルをそのままブラウザで開く…だけではなく、後述の「ローカルサーバーで開く」手順を踏めば
すぐに動きます。フレームワークのビルドステップが無いため、将来自分で改造する際も学習コストが低いはずです。

---

## 1. まず知っておいてほしいこと：APIキーは必須ではありません

「YouTube Data APIキーやTwitchの登録が無いと使えないのでは？」という点について —
**両方とも完全無料・クレジットカード登録不要**で、しかも次の機能は **APIキーなしでも今すぐ使えます**。

| 機能 | APIキー無しで使える？ |
|---|---|
| URLを貼り付けて配信/動画を複数同時視聴 | ✅ 使える |
| 画面サイズ・配置の自由変更、プリセット保存 | ✅ 使える |
| 音量調整・ミュート | ✅ 使える |
| チャット表示・書き込み(公式埋め込み) | ✅ 使える（YouTubeはPC/タブレットのみ。モバイル幅では埋め込み非対応というYouTube側の制限あり） |
| お気に入りチャンネルを手動登録してクリックで開く | ⚠️ 使えるが、確実に再生するにはAPIキー推奨（下記コラム参照） |
| **登録チャンネル/フォロー中チャンネルの自動一覧取得** | ⚠️ ログイン(無料のAPI登録)が必要 |
| **ライブ中かどうかのバッジ表示** | ⚠️ ログイン(無料のAPI登録)が必要 |
| **アーカイブ(過去配信)一覧の取得** | ⚠️ APIキー/ログイン(無料のAPI登録)が必要 |
| **@ハンドルやカスタムURLのチャンネルを自動再生** | ⚠️ YouTube APIキーが必要（チャンネルIDそのものを追加すればキー無しでも可） |

つまり、まずはAPIキー無しでURLをどんどん貼り付けて動作確認していただき、
「登録チャンネル一覧を自動で出したい」となった段階で 2. の手順（10分程度、無料）を行う、という順番がおすすめです。

## 2. 起動方法（ローカルサーバーで開く）

ブラウザの `file://` からの直接オープンだと、ログイン(OAuth)やチャット埋め込みがブラウザの制限で動作しません。
簡易サーバーを1つ起動するだけで解決します。お好きな方法をどうぞ。

### Python がある場合（最も簡単・推奨）
```bash
cd streamviewer
python serve.py
```
ブラウザで `http://localhost:8080` を開く。

※ `python -m http.server` でも動きますが、ブラウザが独自にJS/CSSファイルを
キャッシュしてしまい「ファイルを更新したのに反映されない」ことがあります。
同梱の `serve.py` はキャッシュを無効化するヘッダーを付けて配信するので、
開発中（ファイルを書き換える可能性がある間）はこちらを使うことを強く推奨します。
（Windowsで `python` コマンドが見つからない場合は `python3 serve.py` を試すか、
Microsoft Store からPythonをインストールしてください。）

### 毎回コマンドを打たずに起動する（Windows・PWAを既にインストール済みの場合）

同梱の `start_streamviewer.bat` をダブルクリックすると、
1. `serve.py` をコンソール画面を出さずにバックグラウンドで起動し、
2. すでにインストール済みの「アドレスバーなしアプリ」ウィンドウ（Chromeの
   「ページをアプリとしてインストール」で作った StreamViewer.lnk と同じもの）を開きます。

サーバーがすでに起動中の場合、2つ目の `serve.py` はポート使用中エラーで
何も表示せず自動終了するだけなので、二重起動を気にせず毎回このファイルを
使って問題ありません。使いやすい場所（デスクトップなど）にショートカットを
作っておくと、今まで使っていた `StreamViewer.lnk` の代わりに使えます。

さらに一歩進めて「PCを起動したらサーバーが自動で立ち上がっている」状態にしたい場合は、
Windowsの「タスクスケジューラ」に `pythonw serve.py` をログオン時に実行するよう登録する方法も
ありますが、常駐プロセスが増える／初回設定がやや複雑なため、まずは上記の `.bat` で
様子を見ることをおすすめします。必要であれば設定手順も案内できます。

### Node.js がある場合
```bash
cd streamviewer
npx serve -l 8080
```

### VS Code を使っている場合
「Live Server」拡張機能をインストールし、`index.html` を右クリック →
「Open with Live Server」。

毎回同じポート番号（例: 8080）を使うようにすると、後述のOAuth設定をポートが変わるたびに
直す必要がなくなるのでおすすめです。

## 3. YouTube 連携を有効にする（無料・カード登録不要・約5分）

登録チャンネルの自動取得や、@ハンドル/カスタムURLチャンネルの自動解決に使います。

1. https://console.cloud.google.com/ にアクセスし、Googleアカウントでログイン。
2. 画面上部のプロジェクト選択から「新しいプロジェクト」を作成（名前は何でもOK、例: `streamviewer`）。
3. 左メニュー「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を検索し、「有効にする」。
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **「APIキー」** を選択。
   - 表示されたキーをコピー → アプリの「⚙設定」→ 「YouTube Data API キー」に貼り付け。
   - (任意) キーの「アプリケーションの制限」で「HTTPリファラー」を選び、
     使用するURL（例: `http://localhost:8080/*`）を登録するとより安全です。
5. 同じ画面で「認証情報を作成」→ **「OAuthクライアントID」** を選択。
   - 初回は「OAuth同意画面」の設定を求められます。「外部」を選び、アプリ名(任意)・
     自分のメールアドレスを入力して保存（審査は不要、テスト目的なので「テストユーザー」に
     自分のGoogleアカウントを追加しておいてください）。
   - アプリケーションの種類は **「ウェブ アプリケーション」**。
   - 「承認済みの JavaScript 生成元」に、実際にアプリを開くURLを追加
     （例: `http://localhost:8080`。末尾にパスは付けない）。
   - 作成されたクライアントIDをコピー → アプリの「⚙設定」→
     「OAuth クライアントID」に貼り付け。
6. アプリ右上の「⚙設定」→「保存」。サイドバーの「YouTubeでログイン」ボタンからログインすると、
   登録チャンネルが自動でお気に入りに追加されます。

**無料枠について**: 1日 10,000 ユニットまで無料で、キー自体は無料・カード登録不要です。
チャンネル一覧の取得(`subscriptions.list`)やアーカイブ一覧の取得は1回1ユニット程度と軽量ですが、
「ライブ中かどうかの確認」は1チャンネルあたり約100ユニット消費するため、アプリ内では
自動ポーリングはせず、サイドバーの「🔄 ライブ状況を更新」ボタンを押した時だけ、
確認画面を出したうえで実行するようにしています。

## 4. Twitch 連携を有効にする（無料・カード登録不要・約3分）

フォロー中チャンネルの自動取得、ライブ状況の取得に使います。

1. https://dev.twitch.tv/console にアクセスし、Twitchアカウントでログイン
   （初めての場合は開発者利用の確認が出ますが無料です）。
2. 「アプリケーション」→「アプリケーションを登録する」。
   - 名前: 任意（例: `streamviewer-yourname`。全体でユニークな名前が必要です）
   - OAuth リダイレクトURL: アプリを開くURLそのまま
     （例: `http://localhost:8080/`。**末尾のスラッシュや大文字小文字まで完全一致**させてください）
   - カテゴリ: 「Application Integration」などお好みで
3. 作成後に表示される **クライアントID** をコピー →
   アプリの「⚙設定」→「Twitch クライアントID」に貼り付け。
   「リダイレクトURI」欄には手順2で登録したものと**完全に同じ値**を入力。
4. アプリ右上の「⚙設定」→「保存」。サイドバーの「Twitchでログイン」ボタンを押すと
   Twitchの認証画面に移動し、ログイン後アプリに戻ってきます
   （クライアントシークレットの入力は不要です。安全なブラウザ内OAuthのみを使用しています）。

## 5. デプロイしてスマホ(Android)からも使う

このアプリは静的ファイルだけなので、無料の静的ホスティングにそのまま置けます。

1. GitHub にこのフォルダをpushし、**GitHub Pages** を有効化する。
   または **Netlify** (netlify.com) にこのフォルダをドラッグ＆ドロップするだけでもOKです。
2. 発行されたURL（例: `https://yourname.github.io/streamviewer/`）を、
   手順3・4で登録した「承認済みのJavaScript生成元」「OAuthリダイレクトURL」にも追加登録してください
   （ローカル用の設定はそのまま残しておいて問題ありません、複数URLを登録できます）。
3. スマホのブラウザ(ChromeなどAndroidブラウザ)でそのURLを開く。
   メニューから「ホーム画面に追加」を選ぶと、アプリのようなアイコンで起動できるようになります(PWA)。

※ Android/モバイル幅では、YouTube公式のチャット埋め込みが表示されない場合があります
（YouTube側の仕様上の制限です）。動画の視聴・レイアウト・音量・Twitchチャットは
スマホでも問題なく利用できます。

## 6. 基本的な使い方

- 上部の入力欄、またはサイドバー「配信を追加」にYouTube/TwitchのURL・動画ID・チャンネル名を貼り付けて
  「追加」を押すと、その場でパネルが開きます。
- パネルのヘッダーをドラッグで移動、右下の角をドラッグでリサイズできます。
- ヘッダーのアイコン: 🔊/🔇 ミュート切替、スライダーで音量調整、💬 チャット表示切替、
  🗗 チャットを別ウィンドウに切り離す、↗ 元のサイト(YouTube/Twitch)で開く、✕ 閉じる。
- 🗗を押すと、そのパネルのチャットが独立した1つのパネルとして切り離され、映像と別々に
  自由な位置・サイズに配置できるようになります（元の映像パネルの💬を押すと、映像側に
  くっついたチャットを再度表示できます。切り離したチャット側の✕で閉じても、映像側には
  影響しません）。
- 上部の「自動整列」ボタンで、開いているパネルを綺麗に並べ直せます。
- レイアウト保存機能（プリセット）を使う場合は、右上の 🗂 ボタンを押すとプリセットバー
  （読込/保存/名前を付けて保存/削除/書出/読込(JSON)）が表示されます。初期状態では
  邪魔にならないよう非表示になっていますが、もう一度 🗂 を押せばいつでも表示・非表示を
  切り替えられます（設定はブラウザに保存され、次回起動時も引き継がれます）。
  表示した状態で「名前を付けて保存」を押すとプリセットとして保存でき、次回は
  プリセットを選んで「読込」ですぐ復元できます。「書出」でJSONファイルとしてバックアップも可能です。
- お気に入りは「チャンネル登録/フォロー」とは別の、このアプリ内だけのローカルなリストです。
  ✕で削除してもYouTube/Twitch側の登録自体は解除されません。また、一度削除したチャンネルは
  「覚えて」おかれるので、その後ログインし直しても自動では復活しません（登録/フォローが
  残っている限り、YouTube/Twitch側では引き続き登録されたままです）。もう一度お気に入りに
  出したくなったら、URLを直接貼り付けて追加し直してください。
- サイドバー「お気に入り」でチャンネルをクリックすると、そのチャンネルの現在の配信
  （配信中でなければオフライン画面）が開きます。🕘 アイコンでアーカイブ一覧を確認できます。
- 「＋ グループ」でお気に入りをフォルダ分けできます。各チャンネルの📁ボタンで所属グループを
  設定でき、グループ見出しをクリックすると開閉できます。グループ内に配信中のチャンネルが
  1つでもあると、そのグループ見出しが光ります。グループ見出し左端の ⋮⋮ をドラッグすると、
  グループの表示順を入れ替えられます。
- 「配信中でないチャンネルを非表示」にチェックを入れると、現在配信中と確認できたチャンネル
  だけが表示されます（ライブ状況が未確認のチャンネルも隠れます。「🔄 ライブ状況を更新」を
  押すか、一度チャンネルを開くと判定されます）。配信中のメンバーがいないグループはグループ
  ごと隠れます。チェックを外せばいつでも元に戻ります。
- 配信中のチャンネルは、LIVEバッジの下に配信開始からの経過時間・視聴者数を表示します
  （Twitchは自動、YouTubeは「🔄 ライブ状況を更新」または一度チャンネルを開いた時に取得されます）。
  経過時間はアプリを開いている間、1分ごとに自動で更新されます。

## 7. 既知の制限事項

- **お気に入りチャンネルをクリックしたときに再生に失敗することがある件について**:
  「現在その配信者が配信している動画」をあらかじめ知らない状態でチャンネルを開くには、
  YouTube公式の `embed/live_stream?channel=` という特殊な埋め込みURLを使う必要がありますが、
  この方式はYouTube側の仕様上、自サイト（YouTube以外のドメイン）に埋め込むと
  高い確率で「この動画は再生できません」というエラーになってしまうことを確認しています
  （実在の有名チャンネルで検証済み・チャンネル側の設定の問題ではありません）。
  **YouTube APIキーを設定画面に登録しておくと**、チャンネルをクリックした瞬間にその
  チャンネルの実際の動画IDを1回だけ調べてから開くため、この問題を避けて確実に再生できます
  （教材ページに戻る手間もなく、その場で自動的に行われます）。APIキーが無い場合は
  引き続き上記の埋め込み方式を試みますが、失敗した場合はパネル内に
  「YouTube/Twitchで直接開く」というリンクが表示されるので、そこから視聴してください。
- YouTubeの `@ハンドル` や `/c/カスタムURL` 形式のチャンネルは、APIキーが無いと
  「現在配信中の動画」を自動解決できません。チャンネルの動画URL(`youtube.com/watch?v=...`)を
  直接貼り付けるか、APIキーを設定してください（`/channel/UCxxxx` 形式のURLはキー無しでも動作します）。
- YouTubeチャットの埋め込みは、YouTube側の仕様によりモバイル幅の画面では開けません。
- TwitchのアーカイブVODのチャットリプレイ表示には対応していません(視聴のみ)。
- YouTubeの「ライブ中かどうかの確認」はAPIクォータを多く消費するため、自動更新ではなく
  手動更新（確認ダイアログ付き）にしています。
- 設定(APIキー・クライアントID)やお気に入り・プリセットは、すべてこの端末のブラウザの
  localStorageに保存されます。どこにも送信されません。別の端末で使う場合は、
  「書出」でエクスポートしたプリセットJSONを移す、または各端末で個別にAPI設定を行ってください。

## 8. フォルダ構成

```
streamviewer/
  index.html          エントリーポイント
  css/style.css        スタイル一式
  js/
    main.js             起動処理
    state.js            状態管理 + localStorage永続化
    grid.js              マルチビューキャンバス(ドラッグ/リサイズ/パネル管理)
    chat.js               チャット埋め込み(YouTube/Twitch)
    sidebar.js            サイドバー(お気に入り・アーカイブ・ログイン)
    presets.js            レイアウトプリセット
    settings.js           設定モーダル
    players/youtube.js    YouTube IFrame Player API ラッパー
    players/twitch.js     Twitch Embed Player API ラッパー
    auth/googleAuth.js    Google OAuth (Identity Services)
    auth/twitchAuth.js    Twitch OAuth (Implicit Flow)
    api/youtubeApi.js     YouTube Data API v3 呼び出し
    api/twitchApi.js      Twitch Helix API 呼び出し
    utils/                共通ユーティリティ
  manifest.webmanifest  PWA用マニフェスト
  sw.js                  PWA用サービスワーカー(アプリシェルのキャッシュのみ)
  icons/                 PWAアイコン
  scripts/make_icons.py  アイコン生成スクリプト(Python/Pillow, 再生成用)
```

## 9. 今後の拡張アイデア（実装は含まれていません）

- Electronでラップしてデスクトップアプリ化（今の構成のままElectronの`BrowserWindow`に読み込むだけで動作するはずです）
- YouTube Data API + OAuth送信権限を使った自前チャットUI（モバイルでもチャット表示できるようにする）
- ドラッグ時のグリッドスナップ、パネルの整列ガイド線
- 複数プロフィール（アカウント）切り替え
